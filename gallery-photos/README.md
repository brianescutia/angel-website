# Gallery photos / Fotos de la galería

Every photo in this folder shows up automatically in the **Gallery** section of the website.
Cada foto en esta carpeta aparece automáticamente en la sección **Galería** del sitio web.

## ➕ Add photos / Agregar fotos

1. Click **Add file → Upload files** (top right of this page).
2. Drag your photos into the box.
3. Scroll down and click **Commit changes**.
4. Wait a few minutes — the website updates by itself.

## 🗑️ Delete a photo / Borrar una foto

1. Click the photo's name in the list above.
2. Click the **⋯** menu (top right) → **Delete file**.
3. Click **Commit changes**.

## 🔢 Order / Orden

Photos appear in order by file name: `01-...` first, then `02-...`, and so on.
Photos without a number go after the numbered ones.
To put a photo first, name it something like `00-my-photo.jpeg` before uploading.

## ✅ Tips

- Use **.jpg, .jpeg, .png or .webp**. iPhone **HEIC** photos won't display — export them as JPEG first
  (on iPhone: Settings → Camera → Formats → *Most Compatible*).
- Keep photos under ~5 MB so the page loads fast. Emailing a photo to yourself at "Medium" or "Large" size shrinks it.
- Avoid spaces and accents in file names (use `food-drive-2026.jpeg`, not `Food Drive Año.jpeg`).
- Don't delete this README file.
