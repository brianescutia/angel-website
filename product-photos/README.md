# Tiendita product photos / Fotos de productos de la Tiendita

The photos in this folder appear on the product cards in the **Tiendita** section of the website.
Las fotos en esta carpeta aparecen en las tarjetas de productos de la sección **Tiendita** del sitio web.

Each product uses **one fixed file name** / Cada producto usa **un nombre de archivo fijo**:

| Product / Producto | File name / Nombre del archivo |
| --- | --- |
| White C.A.T.A. Shirt / Camiseta blanca C.A.T.A. | `shirt.jpg` |
| C.A.T.A. Reusable Tote / Bolsa reutilizable C.A.T.A. | `tote.jpg` |

If a product has no photo here, the website shows the sample design drawing instead.
Si un producto no tiene foto aquí, el sitio muestra el dibujo de diseño de muestra.

---

## English

### Add or replace a product photo

1. **On your computer, rename the photo first** to exactly `shirt.jpg` or `tote.jpg` (all lowercase).
2. On this page, click **Add file → Upload files** (top right).
3. Drag the renamed photo into the box. If a photo with that name already exists, the new one replaces it.
4. Scroll down and click **Commit changes**.
5. Wait a few minutes while Vercel redeploys — the website updates by itself.

### Remove a product photo (go back to the sample drawing)

1. Click the file name (for example `shirt.jpg`) in the list above.
2. Click the **⋯** menu (top right) → **Delete file** → **Commit changes**.

### Tips

- The name must match exactly. `Shirt photo.jpg` or `shirt (1).jpg` will **not** show up.
- Use **.jpg** photos. iPhone **HEIC** photos won't display — on iPhone go to
  Settings → Camera → Formats → *Most Compatible* before taking the photo, or export it as JPEG.
- Square or slightly tall photos look best. Keep them under ~5 MB.
- Don't delete this README file.

## Español

### Agregar o reemplazar la foto de un producto

1. **En tu computadora, primero cambia el nombre de la foto** a exactamente `shirt.jpg` o `tote.jpg` (todo en minúsculas).
2. En esta página, haz clic en **Add file → Upload files** (arriba a la derecha).
3. Arrastra la foto al recuadro. Si ya existe una foto con ese nombre, la nueva la reemplaza.
4. Baja y haz clic en **Commit changes**.
5. Espera unos minutos mientras Vercel actualiza el sitio — se actualiza solo.

### Quitar la foto de un producto (volver al dibujo de muestra)

1. Haz clic en el nombre del archivo (por ejemplo `shirt.jpg`) en la lista de arriba.
2. Haz clic en el menú **⋯** (arriba a la derecha) → **Delete file** → **Commit changes**.

### Consejos

- El nombre debe ser exacto. `Foto camiseta.jpg` o `shirt (1).jpg` **no** aparecerán.
- Usa fotos **.jpg**. Las fotos **HEIC** del iPhone no se muestran — en el iPhone ve a
  Configuración → Cámara → Formatos → *Más compatible* antes de tomar la foto, o expórtala como JPEG.
- Las fotos cuadradas o un poco verticales se ven mejor. Mantenlas por debajo de ~5 MB.
- No borres este archivo README.
